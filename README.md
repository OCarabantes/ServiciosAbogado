# Estudio Jurídico Causa

Sitio institucional en Next.js para un estudio jurídico chileno enfocado en mediación y derecho de familia.

## Configuración previa a publicación

Edita `site.config.js` y reemplaza el nombre del estudio, nombre de la abogada, correo, teléfono, WhatsApp, ubicación, horario y modalidad de atención. Revisa también el texto de `pages/privacidad.js`.

## Desarrollo

```bash
npm install
npm run dev
```

## Despliegue en Vercel

Importa el repositorio en Vercel. No requiere variables de entorno. El formulario prepara una solicitud y continúa por WhatsApp; la cita se confirma manualmente.
